# Roadmap

What the notes pane is for, in priority order.

| Area | Status | Notes |
| --- | :---: | --- |
| Markdown preview parity | done | callouts, tables, fences, tasks, setext |
| Paste screenshots | done | attachment folder + reference rewrite |
| Cite a note into chat | done | whole note or selected lines |
| Outline / backlinks | not planned | use a dedicated Obsidian graph view |
| Graph view | not planned | out of scope for a chat-side note pane |

## Next

1. Keep preview parity with Obsidian for the constructs people actually use.
2. Make attachment handling boring: one setting, moves and rewrites safely.
3. Stay out of the way — the panel docks next to the conversation.

> [!warning] Honest scope
> There is no backlink index, no outline pane and no graph. If you need those,
> a full Obsidian vault is the right tool.
